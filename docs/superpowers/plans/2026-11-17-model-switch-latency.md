# 模型切换延迟修复记录

## 问题与证据

用户反馈仿真／实机、SO-100／Adora 和子菜单切换滞后。对原生验证窗口采样确认：界面事件中的 `HardwareScreen::sync` 同步调用 URDF/STL 加载与法线处理，期间无法处理后续输入。其他采集和回放页面也存在相同同步入口。

同一台 macOS、同一组实际模型的开发构建诊断：Adora 原同步解析约 7.2 秒，SO-100 约 0.3 秒。为模型库和 STL 解析库启用开发构建优化后，首次模型准备约为 0.8 秒／31 毫秒；后台缓存命中后约为 26 毫秒／1 毫秒，请求提交低于 0.1 毫秒。这些数字只覆盖模型准备，不包含 GPU 首帧绘制。

## 实现

- [x] 使用单个后台线程解析，每个加载器合并中间选择并通过代次过滤旧结果。
- [x] 缓存最近两个模型，URDF 或资源修改时失效；符号链接资源不使用缓存，避免目标文件变化未被检测。
- [x] 设置、采集、操作和回放页面复用加载器，保留原同步加载 API 的兼容性。
- [x] 后台完成后在界面线程挂载模型，先恢复最新姿态、浮动基座和场景相机，再允许绘制。
- [x] 区分暂时无结果和线程退出；加载错误可见，后续选择可以重建线程。

## 验证

真实控件回归先复现阻塞，再验证首次同步返回、最后选择胜出、加载占位、首帧关节角、场景相机和基座恢复。后台服务测试覆盖队列合并、缓存复用、资源失效、两项容量、符号链接和异常退出。

一轮独立审阅指出的首帧姿态、断开通道与缓存测试问题均已修复。设置页诊断结论没有直接推及其他页面；采集和操作／回放的同步入口另有失败后通过的回归测试。

`cargo test --locked --workspace --no-default-features`：94 项通过，两个既有文档示例忽略，Makepad 脚本错误为零。原生无视频构建与启用视频特性的编译检查均通过。实际窗口已检查仿真／实机、SO-100／Adora、加载期间子菜单跳转及最终模型显示；本轮未连接实机或启动仿真。
