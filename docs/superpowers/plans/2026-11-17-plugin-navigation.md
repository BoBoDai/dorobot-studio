# 插件分组导航实施计划

## 目标与设计

按用户提出的布局，侧栏只显示插件名称，插件面板放在右侧顶部的标签栏。移除旧导航与插件工具箱的重复入口。保留“数据工作区”这一内置入口，将数据集、回放、评估收进其顶部标签；这三个页面本轮仍由宿主管理。

沿用 Rust、Makepad 和现有插件清单，不新增依赖。名称入口优先保证可辨认性；不采用仅图标入口或侧栏内嵌子菜单。切换插件时恢复该插件本次会话中最后使用的面板，快捷键和业务操作触发的跳转也更新分组与标签。

## 实施步骤

- [x] 在 `dorobot-flex/tests/plugins.rs` 添加回归测试，先证明当前工具箱按面板重复列出入口。
- [x] 在 `crates/dorobot-studio-plugin/src/lib.rs` 按插件生成侧栏、按面板生成顶部标签，同步可见性、选中状态和最近面板；保留重载后的实例。
- [x] 在 `dorobot-flex/src/bin/dorobot-flex.rs` 移除旧导航，挂载顶部标签并统一跳转；更新中文文案与插件开发说明。
- [x] 执行插件测试、工作区测试、原生构建和界面检查，检查明暗主题、中英文、分组切换及主题重载。
- [x] 在当前功能分支提交本次界面调整。

## 检查重点

隐藏标签不能被激活；禁用插件不能从侧栏打开；独立插件不依赖旧 `Screen`；主题重载后分组与标签仍存在；后台采集和回放不因导航切换而重启。


## 执行与验证记录

- 原工具箱回归先失败：两个插件生成三个面板入口；按插件生成后通过。
- 一轮独立审阅发现动态标签与宿主短路径重名、禁用页面仍可进入的问题。已分别通过同名 `play` 面板测试和宿主导航测试观察失败，再修复并通过。插件标签采用 `plugin_tab_` 前缀，宿主数据标签查询限定在自己的容器内。
- 保留标签键盘焦点描边，中文验收同时核对实际 `Screen`，避免仅凭同组标题误判。

- `cargo build --locked -p dorobot-flex --no-default-features`：通过；保留既有未使用代码等警告。
- 独立状态目录中的原生窗口已检查：控制／采集／数据工作区切换、顶部标签、快捷键同步、中英文及明暗主题重载。未连接真实机器人或启动仿真。
