# DoRobot Studio v0.1.0-rc.1

A standalone macOS Apple Silicon build with the Nano simulation runtime included.
Unzip the app, move it to Applications, then open **Robot setup → Simulation →
Start simulation**. No system Python, Rust, Dora install or AISLE checkout is
needed to start the bundled Nano environment.

Included: native Makepad Studio, pinned AISLE source, Nexus 0.2.1, Python 3.13.5,
Dora CLI/API 1.0.1, Nano URDF/meshes, three simulated cameras, controller input,
room physics, recording/replay, and the Feetech base adapter. The separate source
archive preserves the Makepad JIT development entry and can reuse the installed
app's runtime through `tools/release/run_jit_macos.sh --video`.

Acceptance on macOS 26.6.2, Apple Silicon:

- 56 Rust library tests passed.
- 16 Makepad user-flow checks passed from a relocated app with an empty HOME,
  system-only PATH, no access to the original source/build/cache directories,
  read-only bundle and external network blocked.
- Recording verified: all three videos decoded 13 frames, 17 measured joints,
  13 raw frame checksums and 39 camera poses; replay advances normally.
- Bundle signature/dependency/privacy checks passed; native deployment targets
  are at most macOS 14.0.
- Makepad JIT check passed with 0 errors.

The minimum deployment target is macOS 14, but older systems have not been
physically tested. This RC is ad-hoc signed and **not notarized**; macOS may
require explicit approval in Privacy & Security when opening the downloaded app.

Real Nano support is currently the Feetech mobile base only; real arm/head
calibration and camera capture are not implemented. Physical hardware was not
used for RC acceptance. The optional SO100/SO101 LeRobot stack is not bundled.
Camera sampling is 5 Hz in simulation time; live 30 FPS is not claimed.

Recordings default to `~/DoRobot/Recordings`; settings and temporary sessions
remain outside the app. No personal settings, recordings, credentials or build
home paths are included. Dependency metadata, license notices and FFmpeg source
are included. AISLE is pinned to `845e31f5d1871905e69c9d838f90a32c62bd6476`;
that upstream snapshot has no top-level license declaration.

See `tools/release/README.md` for the build, verification and JIT workflow.
