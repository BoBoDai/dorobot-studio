# English and Simplified Chinese

Click the **globe icon** at the bottom of Studio's sidebar to switch between
**English / 简体中文**. Hover to see the target language; keyboard activation
and a screen-reader name are available. No app restart or recompilation is
needed to switch. The selected language is saved with the UI
preferences and restored on launch. Existing profiles default to English.
This feature is in source builds after RC.2; the published RC.2 binary is unchanged.

The six pages, workflow controls, camera panels, replay window, calibration
instructions, recording messages, dialogs and input placeholders support both
languages. Switching preserves the current page, panel layout, playback,
recording and unsaved takes. Editable text, dataset/task names, custom camera
names, joint identifiers and paths remain data in their original language.
Brands, protocol identifiers and unrecognized native diagnostics retain their
original text. macOS supplies its own language for system dialog controls.

For a launch-time override:

```sh
./tools/run_jit.sh --language zh-CN
./tools/run_jit.sh --language en
```

Use `--video` when reviewing camera recordings. With an installed RC runtime,
`tools/release/run_jit_macos.sh --video --language zh-CN` also reuses its bundled
native simulation, Dora and video libraries. Set `DOROBOT_APP` to the app bundle
if it is not in `/Applications`.

## Maintaining translations

- `dorobot-flex/resources/i18n/zh-CN.json` maps English UI messages to Chinese.
  English is the fallback for unknown messages.
- `dorobot-flex/src/i18n.rs` retains each widget's source caption so switching
  back does not depend on reverse translation. It localizes text-input
  placeholders, never the editable value, selection or composition.
- `{0}`, `{1}`, etc. are opaque parameters; retain all slots in the translation.
  Captured names, paths and native diagnostics are never recursively translated.
  Only explicitly recognized application status lines are split into components.
- `App::localize` protects labels populated from datasets and devices. Protect
  new data-bearing captions here even if they might equal an English UI label.
- Backend state, Dora messages, controller modes and dataset formats stay in
  their existing protocol language. Do not translate backend enum values or
  controller status strings used by control logic.
- The catalog is embedded by Rust. Changing translations requires a new build
  or JIT process; if the JIT retains an old `include_str!` result, also touch
  `dorobot-flex/src/i18n.rs` before restarting. Switching languages does not.

## Validation

Verified on macOS Apple Silicon on 2026-11-16: 60 library tests passed, the JIT
check reported zero errors, and 18 interactive journey assertions plus two
fresh-process restore assertions passed. Chinese screenshots were reviewed in
light and dark mode. The journey used native simulation; no physical robot was
connected for this localization check.

Run `cargo test --locked -p dorobot-flex --lib` for source round trips,
parameter integrity, catalog consistency, camera-name preservation and old
preference compatibility. Run `./tools/run_jit.sh --check --video` with the
video development libraries configured to check the JIT entry.

`tools/ux/i18n_journeys.py` uses Makepad instrumentation for real clicks and
screenshots. Launch a separate app with a disposable
`DOROBOT_STUDIO_STATE_DIR`, `DOROBOT_UX_REPORT`, and a copied Nano dataset named
`Record`. Set its task to `Record / 中文任务 {0}` in both `meta/tasks.jsonl` and
`meta/episodes.jsonl`, then pass it with `--dataset`. Never run the journey
against an active user session: it starts simulation and records a small take.

```sh
python3 tools/ux/i18n_journeys.py \
  --pid "$TEST_APP_PID" --remote "$MAKEPAD_REMOTE" \
  --report "$TEST_UI_REPORT" --state-dir "$TEST_STATE_DIR" \
  --out "$TEST_OUTPUT"
```

The journey checks all six navigation labels, reversible switching during
playback and recording, maximized panels, the second replay window, input
values, saved task metadata and preference storage. It captures Chinese
screenshots in light and dark mode. Quit the test app, relaunch with the same
state directory and no `--language` override, then repeat with `--restore-only`
to verify persistence without starting hardware or simulation.
